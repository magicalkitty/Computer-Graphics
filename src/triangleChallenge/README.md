# Read the Triangle Data

Simple code to read a big list of triangle vertices. Can your code render this list of triangles?

### Compile the Test

Instructions for Linux or macOS, for reference:

```
g++ -std=c++17 -o readTriangleVerts readTriangleVerts.cpp
```

### Run

```
% ./readTriangleVerts 
Number of floats: 626994
Interpreted as Vertices: 208998
Interpreted as Triangles: 69666
```
